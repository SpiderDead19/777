# ИИ-Снабженец 3.0 — онлайн и Windows

Рабочий закупочный кабинет: PDF/XLSX → сопоставление номенклатуры → автоматический план → ручная корректировка → общая Excel-таблица и отдельные заявки.

## Возможности

- до 20 коммерческих предложений (.xlsx и текстовые .pdf) за один расчёт;
- разбор колонок «артикул / описание / количество / цена / бренд / срок» в разных структурах;
- объединение всех предложенных позиций, а не только строк первого файла;
- сопоставление по артикулу и по похожему названию с пометкой сомнительных совпадений;
- ручное правило качества для каждого поставщика («По данным КП», «Всё оригинал», «Все аналоги»);
- для **ТД СК НОВОСИБ** настройка «Всё оригинал» предложена по умолчанию согласно уточнению заказчика;
- настраиваемый вес качества (60%) и цены (40%) для предварительного выбора;
- три стратегии автовыбора: «Цена и качество», «Минимальная цена», «Только оригинал»;
- ручная замена поставщика отдельно для каждой позиции с защитой от выбора отсутствующей цены;
- цены в RUB, EUR и ручной курс EUR/RUB;
- расчёт плановой суммы и экономии относительно максимальной сопоставимой цены;
- предупреждения по аналогам, отсутствующим количествам, несовпадениям и срокам;
- XLSX с планом закупки, зелёной подсветкой выигравших цен, рисками и итогами;
- отдельный XLSX каждому поставщику **без цен конкурентов**;
- единый ZIP со всеми заявками поставщикам;
- вход по паролю, который хранится в секретах Streamlit Cloud, не в коде.

**Внимание:** «оригинал» в интерфейсе означает заявленный тип качества по КП или установленное пользователем правило. Это не проверка подлинности. Рейтинг брендов — ориентир для снабжения, а не испытания качества. Перед заказом перепроверьте совместимость, НДС, валюту, логистику, наличие и гарантию.

**Облачное хранение:** эта версия не записывает загружаемые файлы и расчёты в GitHub, SQLite или другие внешние базы. Обработка выполняется в сессии веб-приложения; загруженные документы находятся в памяти сервера во время работы сессии. Данные **не** передаются во внешние AI API. Для постоянной истории и корпоративного SSO нужна следующая версия.

## Запуск на компьютере

Из корня проекта:

1. Установите Python 3.12.
2. Выполните \`pip install -r requirements.txt\`.
3. Установите переменную окружения \`SNAB_ACCESS_PASSWORD\` с **собственным сложным паролем** (не сохраняйте пароль в Git):
   - Windows PowerShell: \`$env:SNAB_ACCESS_PASSWORD = "ВАШ_ДЛИННЫЙ_ПАРОЛЬ"\`
   - Linux/macOS: \`export SNAB_ACCESS_PASSWORD='ВАШ_ДЛИННЫЙ_ПАРОЛЬ'\`
4. Запустите \`streamlit run online_app.py\`. Откройте адрес, который покажет Streamlit (обычно \`http://localhost:8501\`).

При отсутствии пароля приложение **не открывает доступ** к загрузкам и анализу.

Для локального запуска двойным щелчком используйте `start.bat`: он включает локальный режим и не требует облачного пароля.

## Готовая Windows-версия

Пользователю не обязательно устанавливать Python. В GitHub откройте **Actions → Build Windows EXE → Run workflow**. После успешной сборки скачайте артефакт **AI-Snabzhenets-Windows** и запустите `AI-Snabzhenets.exe`.

Если Python уже установлен, `build_exe.bat` собирает тот же файл локально в папку `dist`. Скрипт сначала проверяет рабочий `py -3`, затем `python`, поэтому ярлык Microsoft Store больше не принимается за установленный Python.

## Публикация на Streamlit Community Cloud

1. Сначала **слейте PR онлайн-версии в \`main\`** после прохождения тестов. Репозиторий сейчас публичный: для чувствительных коммерческих данных предпочтительнее отдельный приватный репозиторий и приватная конфигурация приложения.
2. Откройте https://share.streamlit.io и войдите через GitHub.
3. **Create app** → **Yup, I have an app**.
4. Repository: \`SpiderDead19/777\`; branch: \`main\` после merge; Main file path: \`online_app.py\`. Для тестового запуска без merge используйте \`feature/online-ai-snabzhenets\`.
5. **Advanced settings → Secrets**: укажите реальный пароль (пример ключа, не рабочий пароль):

   \`\`\`toml
   SNAB_ACCESS_PASSWORD = "придумайте-свой-длинный-сложный-пароль"
   \`\`\`

   **Не добавляйте этот пароль в репозиторий и не отправляйте в чат.**
6. Нажмите **Deploy**. После фактического развёртывания появится URL на \`streamlit.app\`. Сам по себе GitHub Pull Request сайт не запускает.
7. В настройках приложения ограничьте доступ, если требуется конфиденциальность. Простой общий пароль **не заменяет** полноценную корпоративную авторизацию и аудит доступа.

Документация: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy

## Ограничения первой онлайн-версии

- PDF с изображениями/сканами без текстового слоя может потребовать OCR (пока не реализован).
- Универсальные таблицы Excel разбираются эвристически; нестандартную форму КП нужно сначала проверить в интерфейсе.
- Не реализована постоянная история закупок на сервере и централизованные роли пользователей.
- Рекомендации основаны на правилах сопоставления и классе качества; LLM-анализ аналогов пока не подключен и не имитируется.
- Точные суммы требуют подтверждённого количества и сопоставимости НДС/условий поставки.
- При размещении в облаке коммерческие данные обрабатываются на стороне выбранного хостинга.
