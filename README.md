# PDF Invoice Comparator

Приложение для сравнения двух счетов в формате PDF.

## Возможности

- загрузка двух PDF-счетов;
- извлечение товарных позиций из текста PDF;
- сопоставление по артикулу и названию;
- сравнение цен и расчет разницы;
- выгрузка результата в Excel.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Структура

- `app.py` — интерфейс Streamlit;
- `pdf_parser.py` — извлечение строк из PDF;
- `matcher.py` — сопоставление позиций;
- `requirements.txt` — зависимости.

Первая версия использует универсальный текстовый парсер. Для конкретных форм счетов правила извлечения можно настроить отдельно.
