# ИИ-Снабженец 3.0

Приложение для закупочного анализа коммерческих предложений поставщиков.

## Что умеет

- загружает до 20 предложений в PDF/XLSX;
- сопоставляет позиции по артикулу и похожему названию;
- сравнивает RUB и EUR по заданному курсу;
- учитывает заявленный класс качества;
- выбирает минимальную цену, баланс цены/качества или только оригинал;
- позволяет вручную заменить поставщика для любой позиции;
- считает плановую сумму, экономию и распределение по поставщикам;
- формирует общую сводную Excel-таблицу, отдельные заявки и общий ZIP;
- отмечает сомнительные совпадения, аналоги, отсутствующие сроки и количества.

## Быстрый запуск

Windows: запустите `start.bat`.

Через командную строку:

```bash
python -m pip install -r requirements.txt
SNAB_LOCAL_MODE=1 streamlit run online_app.py
```

Подробная настройка онлайн-доступа и сборки Windows: [README_ONLINE.md](README_ONLINE.md).

## Проверка

```bash
python -m unittest discover -s tests -v
```

Старые файлы `app.py` и `matcher.py` сохранены для совместимости с первой версией. Актуальный интерфейс запускается из `online_app.py`, расчётное ядро находится в `online_core.py`.
